# Web Checkout (Razorpay) — DEPRECATED

> **This feature has been removed.** Razorpay is no longer used.
> All payments (one-time purchases, subscriptions, deposits) go through
> **Google Play Billing** exclusively. See [play-billing.md](play-billing.md).

---

> *Previously this plan covered a dual-gateway approach (Razorpay for web,
> Play Billing for Android). That approach was dropped — Play Billing is now
> the sole payment gateway for all purchase types and platforms.*
